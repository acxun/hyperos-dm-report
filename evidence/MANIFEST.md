### 反编译

- 工具：JADX 1.5.6，`jadx -d <out> --no-res <apk>`
- 完整源码树：`evidence/decompiled/full/<App>/`（不入库）
- 关键类：`evidence/decompiled/key/<App>/`（入库），覆盖采集、加密、上报、队列、组件暴露等逻辑

### 证书

- `pub.cer`：SystemHelper 内置，DER 格式，自签名 `O=UNICOM`
- `pub.pem` / `pubkey.pem` / `pub_cert_text.txt` / `pubkey_text.txt`：便于复核

### 数据库

- 仅提供 `.schema.sql` 与 `.counts.csv`（结构与行数），不包含任何数据行
- 原始 DB 含个人信息，保留在 `private/`，不入库

### PCAP（原始文件不入库）

- 原始 pcap 已从公开仓库及全部 Git 历史移除，仅保留在本地 `private/pcap/`
- `B_*.pcap`：1,024 字节设备信息包（429）
- `R_*.pcap`：68,784 字节信号历史包（429）
- `A_*.pcap`：40,464 字节 App 清单包（含 429 与 200）
- 载荷均为 AES 密文，明文不在包内
- 移除原因：链路层含设备/路由器 MAC、内网 IP、DNS 查询与时间戳

### 解密数据（private，不入库）

- `private/A_decrypted_live_ID72.json/.csv`：169 个 App
- `private/R_decrypted_ID47.json/.csv`：100 条位置/基站
- `private/A_decrypted_ID59.json/.csv`：队列明文（旧）
- `private/report_internal.md`：含隐私数据的内部报告
